# Code of Conduct

MoFFT follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants must provide a welcoming, respectful, and harassment-free
environment. Examples of unacceptable behavior include harassment, personal
attacks, discriminatory language, deliberate intimidation, and publishing
another person's private information without permission.

Project maintainers are responsible for clarifying and enforcing these
standards. Report conduct issues privately through the security contact listed
in `SECURITY.md`. Maintainers will review reports promptly, protect reporter
privacy where possible, and take proportionate corrective action.
