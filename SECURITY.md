# Security policy

## Supported versions

Security fixes are applied to the latest revision of the `main` branch until
the project begins publishing versioned releases.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. If that feature is unavailable, contact the repository owner
privately rather than opening a public issue. Include affected revisions,
reproduction steps, impact, and any proposed mitigation.

Do not include credentials, private benchmark data, or third-party personal
information in a report. The maintainers will acknowledge a report as soon as
practical and coordinate disclosure after a fix is available.
