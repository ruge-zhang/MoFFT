# MoFFT 0.4.0 Preview 1 — Apple M5

This preview delivers a downloadable C FFT library for Apple M5/macOS arm64.
The primary distribution is a library source archive with pre-generated
kernels. An optional prebuilt static SDK is also available. Both include a
C consumer example and an Apache-2.0 license; SHA-256 sidecars accompany the
archives.

## Requirements and scope

- Apple M5, macOS 26.4 or newer, and SME2. FP64 also requires SME F64F64.
- Source builds require Apple Clang 21 with SME/SME2 ACLE support and CMake
  3.24 or newer. They do not require Python, calibration, or kernel generation.
- FP32 and FP64 one-dimensional complex FFTs, forward and backward, in-place
  and out-of-place. Supported lengths have prime factors in 2, 3, 5, 7, 11, 13.
- A plan/execute/destroy C interface inspired by FFTW, not an FFTW ABI or
  complete API replacement.

## Planning choices

`MOFFT_FLAG_PRETUNED` uses embedded plans for exact preset cases, with model
fallback for other supported transforms. This preview includes presets for
lengths 169, 256, and 1024 in both precisions.

`MOFFT_FLAG_MEASURE` searches a bounded set of linked kernel banks,
decompositions, and layouts at plan creation. It does not generate code,
recalibrate the processor, or guarantee a global optimum. Selected plans can
be explicitly exported and imported for reuse with the same library build
and CPU family.

## Validation and limitations

The M5 implementation passed correctness, planning, recipe, kernel-bank,
compiler, and package-consumer checks. The extracted source archive was
built, tested, installed, and linked into a separate C application. FP32 and
FP64 PRETUNED, MEASURE, and saved-plan workflows were exercised.

This is a functional preview, not a stable release or a new formal performance
result. Its packaged choices are not the historical paper-tuned binaries.
No iOS/iPad validation is claimed for this release.
